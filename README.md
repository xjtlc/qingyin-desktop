# 青音 · 概念桌面版

为 Windows 制作的非官方本地音乐播放器，使用酷狗音乐**概念版**账号和接口（lite / appid 3116）。

## 打开与登录

1. 双击桌面上的「青音 · 概念桌面版」快捷方式。
2. 点击右上角账号按钮，使用手机上的**酷狗音乐概念版 App**扫描二维码，并在手机上确认。
3. 登录后进入「我的歌单」，读取该账号的歌单；搜索歌曲后点击播放。

登录令牌保存在本机，使用 Windows 账号加密。退出登录会清除令牌。程序不收集账号密码。

## 功能

0.1.49 列表操作对齐与快捷定位：播放、加入队列、刷新及排序按钮的图标和文字统一水平垂直对中；歌曲列表右侧显示悬浮「到顶 / 定位当前 / 到底」，滚动列表时位置保持固定，预留右侧空间，不遮挡歌曲操作。定位会将当前播放行移到可视区域中央并短暂描边；当前歌曲不在本列表时禁用定位，空列表和歌单卡片页隐藏悬浮栏。

0.1.48 日常听歌体验：搜索框支持本机搜索历史、键盘选择、单条删除和清空；歌曲旁新增「下一首播放」，随机播放和单曲循环下也会优先播放一次；队列可清空并在 9 秒内撤销，撤销后保持暂停。顶部时钟可设 15、30、60 分钟、自定义 1–180 分钟或本首播完后暂停，内置与 mpv 播放均生效，最小化时照常计时。顶部键盘按钮列出快捷操作：空格暂停、Ctrl+方向键切歌、左右方向键跳转 5 秒、上下方向键调音量、M 静音、Q 队列、L 歌词、Ctrl+K 搜索。快捷键在当前窗口内生效，输入和滑块操作保留原有按键。

0.1.47 私人歌单登录恢复：歌单接口拒绝旧会话时，核对账号授权后正常续期并重试一次；无法续期则明确显示扫码登录入口，重新授权后自动加载歌单。有效账号的旧设备信息可正常重新注册一次。并发请求共享恢复过程，退出或切换账号后丢弃旧结果；网络超时与手机安全验证分别显示，不再把登录失效误报为网络断开。

0.1.46 全屏时自动隐藏任务栏歌词：全屏游戏、全屏视频及演示时隐藏歌词并取消置顶，返回普通窗口后自动恢复当前句；普通最大化窗口继续显示。隐藏期间播放和歌词计时照常推进，手动关闭歌词后退出全屏也不会重新开启。

0.1.45 任务栏歌词尺寸与位置：按完整任务栏参考图缩小字号，移至任务栏更左侧，采用常规字重并保持垂直居中。在 150% Windows 缩放下，字号约 21 像素、文字左边距约 56 像素；透明底色、逐字变蓝与长句滚动继续沿用。

0.1.44 任务栏歌词改为透明单行显示：未唱部分为灰色，已唱部分随时间变蓝；酷狗逐字歌词使用真实的词时间，长句跟随演唱位置横向移动。优先读取 KRC 逐字歌词，只有 LRC 时使用整句时间显示进度。歌曲 hash 用于匹配对应录音版本，下载后的逐字时间与播放进度持续同步；暂停、进度跳转、切歌和最小化时同步更新，歌词页的开关继续生效。

0.1.43 任务栏歌词：当前歌词显示在 Windows 底部任务栏左侧，关闭青音内的歌词页或最小化窗口后也会跟随播放，暂停时保持当前句。歌词页右上角可开启或关闭任务栏歌词，选择会保存在本机。切歌、进度跳转和 mpv 播放使用同一时间信息同步；本地音乐支持同目录同名 `.lrc`，支持时间偏移和常见文本编码。任务栏歌词条不接收鼠标点击，任务栏按钮可照常使用；自动隐藏或非底部任务栏时暂停展示。

0.1.42 账号推荐和封面：每日推荐接入酷狗账号的每日歌曲推荐；侧栏「搜索音乐」改为「猜你喜欢」，接入酷狗私人 FM，支持换一批、整批播放和加入队列；顶部搜索框照常使用。账号日推按当日和账号缓存，退出后清空。歌单优先展示平台封面，缺图时读取歌单歌曲的专辑封面，空歌单使用专属唱片插画；移除侧栏底部客户端标识。真实账号只读实测取得每日推荐 30 首、猜你喜欢 5 首，个数以平台当前返回为准。

0.1.41 歌词页：使用当前专辑封面形成柔和背景，分开展示歌名、歌手和专辑；同步歌词保持固定字号与行距，平滑高亮、居中跟随。点击歌词或按 Enter 跳转；手动滚动时暂停跟随 6 秒，也可点击「回到当前歌词」立即恢复。支持浅色、深色、小窗口和减少动态效果设置。

- 酷狗概念版扫码登录、真实音乐搜索、账号歌单、在线播放。
- 播放队列、上一首 / 下一首、音量、进度、播放模式、歌词。
- 添加本地 MP3、FLAC、WAV、M4A、OGG 等音乐文件。
- 本机收藏和本机播放记录；这些数据保存在电脑上。

音乐是否可播放、是否仅可试听，由概念版接口和账号权益决定。手机端的签到、领会员等活动不包含在这个客户端中。接口变化或平台验证可能导致登录、歌单或播放暂时不可用，界面会显示实际错误。

## 文件与数据

- 源码：本文件所在项目目录。
- 可运行程序：`dist/QingyinConcept-win32-x64/QingyinConcept.exe`。
- 用户数据：`%APPDATA%/QingyinConcept/`，其中 `account.enc` 是加密账号数据。
- 本地音乐通过文件引用播放，不复制或删除原始音乐。

## 开发

Node.js 24 与 pnpm 可用于安装依赖。执行 `pnpm install`、`pnpm start`；执行 `pnpm build` 创建 Windows x64 可运行目录。保留 `pnpm-lock.yaml` 可复现依赖版本。

**测试环境隐私**：部分可选 UI 验证脚本需要 Playwright（少数额外需要 Sharp），它们通过 `scripts/test-deps.cjs` 从项目安装的依赖或 `QINGYIN_TEST_MODULES` 指向的私有 `node_modules` 目录加载，不依赖固定的用户主目录。可选截图测试通过 `QINGYIN_REFERENCE_COVER` 指定个人本地图片路径，该路径不会写入源码或 Git 仓库。不要提交真实登录 Cookie、令牌、用户配置及测试截图。

## 开源来源

接口适配基于 [MakcRe/KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi)，MIT License，源码版本 `da5ccfd9304c043085a2fd18e94ebc5c315044ab`。上游许可证保留在 `vendor/kugou-api/LICENSE`。

本地修改：固定概念版平台；二维码创建使用概念版 appid；平台要求安全验证时停止请求并提示在手机 App 完成验证。

0.1.1 播放兼容修复：保留平台原始音频地址和备用地址，验证音频内容，通过本地流协议播放并支持进度跳转；播放失败仅显示一次中文提示。

0.1.2 默认优先选择最高可播放音质：按歌曲提供的高音质无损、FLAC、320 kbps、128 kbps 资源选择，受账号权限和音频格式支持限制时自动回退。播放器显示实际验证的格式、码率、采样率和位深；本地音乐保留文件原音质。

0.1.3 完整比较普通地址和账号授权地址提供的无损版本，防止较低规格的无损资源使筛选提前结束。

这不是酷狗官方发布的电脑客户端。首次扫码授权和私人歌单、会员歌曲的验证需要账号持有人操作。
